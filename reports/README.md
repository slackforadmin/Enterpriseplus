# 활용도 리포트 (Usage reports)

Cloudflare Web Analytics 기준 홈페이지 활용도 스냅샷입니다.
날짜별로 한 장짜리 HTML 리포트를 보관합니다.

- 이 폴더는 **사이트에 배포되지 않습니다** (Next.js는 `public/`·`app/`만 서빙).
  저장소 보관용이며, 저장소가 공개 상태이면 저장소를 보는 사람은 열람할 수 있습니다.
- 새 리포트: `enterpriseplus-활용도-리포트.html` 상단 `DATA` 블록을 갱신한 뒤
  `reports/활용도-리포트-YYYY-MM-DD.html` 로 추가하세요.
- 보기: 파일을 브라우저로 열면 됩니다. PDF로 남기려면 인쇄(⌘P) → "PDF로 저장".
